\begin{frame}{Communication in this Module}
    \mytext{
    \begin{itemize}
        \item subsequent lectures will be Zoom
        \item live, using green screen
        \item cameras switched on 
        \item perfectly interactive!
        \item avoid joining together on one machine
    \end{itemize}
    }
    \mycomment{
        Make sure you test your equipment. A good microphone or headsets help. Joining together impairs communication, as not all of you will be visible and audible. It also is prone to create feedback loops and disturb other people in the same room.

        Generally, \enquote{hybrid} events are much more prone to technical failure and offer only drawback to pure online events, where everyone is equally audible and visible.

        I strongly advise you to hook up a second monitor to your laptop. Personally, I have two 3.440 x 1.440 monitors. So I can see all participants, my lecture slides, media centre, and additional files at once.
    }
\end{frame}

    You are also encouraged to stay longer after the end of the meeting if you have questions. 
    }
