\section{Case Study: Loft Bed}

\begin{frame}{Project Loft Bed}
    \showmybitmap{../shared/img/hochbett2.jpg}
    \mycomment{
    
    This is an example for a seemingly simple, \enquote{student size} project: Carlos' project to build a loft bed.

    This project was estimated to cost 200 Euro, and be finished in a week or two.

    It took almost two years to complete. 
    
    And if you look, it is not even completed: it does not (yet) have a ladder or stairs to access the platform.
     
    }
\end{frame}

\begin{frame}{Project Loft Bed }
    \mycomment{
    Carlos started buying these poles of wood. It turned out they had to be cut to size, fitted with some joints, sanded down, painted, transported, assembled.

    And for this, he actually figured he'd need space to do this, means to transport, help with carrying, emptying out his room for the installation, and also to buy colours and bolts.

    Then he actually wanted to borrow my drill...
    }
        \showmybitmap{../shared/img/hochbett0.jpg}
    \end{frame}

\begin{frame}{Project Loft Bed }  
    \mycomment{
    It turned out that he had not measured the space he really had available, and that he hadn't thought about the platform he was actually to build, which turned out to be a project of its own, including ordering material, sanding and painting it, etc.
    }
        \showmybitmap{../shared/img/hochbett1.jpg}
    \end{frame}

\begin{frame}{Project Loft Bed }    
        \showmybitmap{../shared/img/hochbett3.jpg}
    \mycomment{
    When this was done, it was almost as if ready. However, he realised he'd need some sort of carpet, that he'd want some electricity up there, that he'd do well with some sort of protection from falling down, and last but not least, a ladder to actually get up there!
    }
    \end{frame}
