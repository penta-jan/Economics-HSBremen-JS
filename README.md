This is content of classes I teach at Hochschule Bremen, and work in progress.
The content is present in two forms of HSB beamer slides, using a common shared base of diagrams.
The gist is hsbcommon.sty which allows the same, beamer-configures content to be compiled as a white paper script, complete with floats and indexes.
So far, this contains (in the order of creation)
Project Management
Foreign Trade and International Organisations
Microeconomics
Macroeconomics and Economic Policy.
Content was created by me.
AI was used for refactoring and some of the more advanced step system (forest).
